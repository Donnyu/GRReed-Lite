# GRReed Lite 👁️📄

**GRReed** — это легковесный OCR-сервер для распознавания текста, который работает полностью офлайн и разворачивается в один клик.

## 🚀 Возможности
- Распознавание текста (русский + английский) прямо в браузере.
- Работа с фото, скриншотами и вставкой из буфера обмена (Ctrl+V).
- Умная предобработка изображений (OpenCV): удаление шума, увеличение, выравнивание перспективы (Deskew).
- Экспорт распознанного текста в `.docx` (Word).
- Портативность: собирается в один `.exe` файл, не требует установки Python или Tesseract.

## 🛠️ Стек технологий
- **Бэкенд:** Python, FastAPI, Uvicorn
- **Компьютерное зрение:** OpenCV, Tesseract OCR
- **Фронтенд:** HTML, Tailwind CSS, Vanilla JS
- **Экспорт:** python-docx

## 🏃‍♂️ Как запустить (Готовый EXE)
1. Перейдите в раздел [Releases](https://github.com/ТВОЙ_НИК/GRReed-Lite/releases).
2. Скачайте файл `GRReed.exe`.
3. Запустите `GRReed.exe` (он сам поднимет локальный сервер).
4. Откройте в браузере `http://localhost:8000`.
*(В EXE уже вшиты все зависимости, включая Tesseract OCR и языковые пакеты).*

## 💻 Как запустить (Из исходников)
1. Клонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Запустите сервер: `python main.py`.
4. Откройте `http://localhost:8000`.
*(Для запуска из исходников убедитесь, что в папке `tesseract/` лежат файлы движка, либо установите Tesseract OCR в систему).*
